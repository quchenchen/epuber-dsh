# 多平台改写分发

提供一稿多发的平台适配方法。核心纪律：**改写不改变事实与结论，观点强度不升级**。

## 适用范围

- 适用：已定稿内容向多平台分发前的适配改写。
- 不适用：原稿创作；未经授权的他人内容改写（先确认版权与可改写范围）。

## 输入

原稿及其版权状态、目标平台清单、各平台格式与合规要求。缺平台要求时按本技能的通用适配规则执行并注明。

## 平台适配矩阵

| 平台 | 形态要点 | 改写纪律 |
| --- | --- | --- |
| 微信公众号 | 保留深度与结构层次；小标题导航；段落短于原稿 | 标题不标题党；导语 3 行内给核心事实 |
| 视频号/短视频脚本 | 转口语化分镜：镜号、画面、口播、字幕、时长 | 时长压缩不删除关键事实；口播与字幕一致 |
| 微博/快讯 | 压缩到平台字数内，保留核心事实与出处 | 数据与结论不简化到失真 |
| 官网/内刊 | 恢复正式文风，按企业口径校准 | 领导活动、数据表述按审定版本 |

## 执行流程

1. **锁定原稿**：确认版本与修订号；版权、转载授权与署名要求先确认。
2. **逐平台改写**：按矩阵执行；每个平台版本独立成文件，注明基于的原稿修订。
3. **事实一致性核对**：改写后对照原稿逐条核对数字、引语、结论；发现因压缩导致歧义时回到原稿表述。
4. **平台合规核对**：各平台的发布时间、敏感词、广告标识要求单独核对。
5. **分发记录**：发布后把各平台链接、发布时间与效果数据登记到项目资产，作为复盘输入。

## 工具与边界

改写在文本层面完成；排版与发布使用用户明确授权的实际渠道工具，本技能不代发布。审校配合 workdsh-news-desk 技能执行。

## 交付与检查

交付各平台版本文件 + 事实一致性核对记录 + 分发清单。标准：任何平台版本单独看事实无误、与原稿结论一致、观点强度未升级。
