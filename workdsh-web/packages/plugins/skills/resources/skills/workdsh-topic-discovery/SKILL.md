# 选题发现与策划

提供选题从发现到立项的方法。融合编辑选题审查的证据规则与内容日历管理方法；选题评估维度可用项目指令按媒体定位调整。

## 适用范围

- 适用：选题库建设、选题会准备、选题评估与排期。
- 不适用：稿件的采访与写作执行（立项后转入对应稿件项目）。

## 输入

媒体定位与栏目设置、项目指令中的评估维度、可用的信息检索能力。缺栏目设置时先按「要闻/行业政策/深度/一线」四类建初始结构。

## 执行流程

1. **固定渠道跟踪**。按项目指令列出的渠道分类跟踪：上级精神与政策发布、行业动态、企业中心工作、重要时间节点、舆情热点、上级单位与同行业同类媒体账号动态。前五类扫信号；第六类做对标盘点——记录同类账号已发什么、哪些角度被证明可做、哪些角度尚未覆盖，避免与上级单位口径撞车或选题同质化。每类渠道记录最近一次检查时间，滚动更新。
2. **选题条目登记**。每个选题写成结构化条目：核心问题、目标读者、预期体裁、信源线索、时效窗口、拟投放栏目。缺项的选题标「待补」进储备区，不进立项区。
3. **证据化评估**。对每个候选选题回答三个问题：事实基础是否可核验（有 A/B 级信源线索）？与读者利益的相关点是什么？时效窗口还有多久？重大主题或易生争议的选题加做**横纵对照**：横向——同类信源交叉比对，各来源说法一致、分歧在哪；纵向——同一事项的历史脉络，此前报道如何表述、口径有无演变。评估维度固定记录：导向安全、新闻价值、专业价值、可操作性。导向安全存在疑问的选题直接标注「提请报备」，不进入常规排期。
4. **分级流转**。明确区分「已立项 / 储备 / 搁置」三个状态；搁置必须写原因，避免反复重新评估同一选题。
5. **排期与联动**。立项选题写明目标完成时间与负责环节；与稿件项目联动时在活动记录中注明关联，避免选题库与执行进度两张皮。
6. **周期盘点**。按项目节奏（周/月）盘点：过期选题清理、储备转立项、重复选题合并。

## 工具与边界

信息检索使用系统实际提供的能力；选题条目与排期保存在项目计划待办与资产中。本技能不代做采访，不对未核实的线索下结论。

## 交付与检查

交付选题条目清单（含状态与评估记录）与盘点结论。标准：每个已立项选题都有可核验的信源线索与时效判断，储备与搁置状态清晰可追溯。
