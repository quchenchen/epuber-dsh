# 视频脚本生产

提供视频脚本的写作方法，交付可执行的分镜表。本技能只覆盖脚本阶段；拍摄、剪辑与成片制作由实际制作环节完成。

## 适用范围

- 适用：宣传片脚本、新闻短视频脚本、微记录脚本、口播类视频脚本。
- 不适用：成片剪辑、特效制作、素材生成。

## 输入

视频主题与宣传口径、目标平台与时长、可用素材清单或拍摄条件。缺拍摄条件时脚本按素材实际可得性写，不写拍不到的画面。

## 写作方法

1. **结构先行**：先写结构大纲——开场钩子（前 3 秒）、主体（按逻辑分 2-4 段）、结尾（行动点或落版）；总时长分配到大纲段落。
2. **分镜表格式**：镜号、画面内容、口播/字幕、时长、素材来源（实拍/资料/动效）五列齐备；每镜时长按口播语速（约 4 字/秒）反推。
3. **口播规范**：短句口语化，一句一个信息点；字幕与口播一致，专有名词写全称；数字口播处理易错音。
4. **口径纪律**：重大主题脚本先按项目流程报备再制作；领导画面、政策表述、数据引用以审定版本为准。
5. **版权清单**：脚本中引用的音乐、字体、资料素材逐项登记来源与授权状态，不留「后补」项。
6. **静态先行**：低成本静态阶段确认创意，再进高成本制作——脚本（纸面）→ 关键画面参考图或首帧（静态视觉确认，构图、口径、文字信息在这一步定稿）→ 实拍或生成（高成本执行）。避免高成本阶段才发现构图或口径问题而返工。
7. **制作资产登记**：系列或多集内容建立设定登记——出镜人物（身份、职务、口径）、场景、关键道具与企业标识逐项登记，跨集保持一致；单集内容按需简化。需要 AI 生成分镜参考图或视觉稿时，读取 [references/storyboard-prompt-template.md](references/storyboard-prompt-template.md) 按八维分镜描述法写画面描述，实际生成以系统可用图像能力为准。

## 完成判定门

脚本交付前过四道门，任何一道不过不出稿：口播试读通过（时长与节奏匹配）；每镜素材来源明确（拍得到或已持有）；版权清单零未登记项；敏感表述与口径全部对照审定版本。

## 工具与边界

分镜表以表格或文档交付；拍摄执行与成片不在本技能范围内，不承诺生成视频文件。

## 交付与检查

交付分镜表 + 结构大纲 + 版权清单 + 拍摄/剪辑需求清单。标准：摄制人员拿表可直接开机、口播可试读通过、无未授权素材项。
