# 人民日报新闻稿写作

提供党报要闻版与评论版文风的写作方法。本技能为**公开通行体例的初版基线**：具体版面定位、栏目要求与审定口径以项目指令和项目审定资料为准。

## 适用范围

- 适用：要闻消息、评论文章、政论式综述。
- 不适用：市场行情资讯、娱乐内容、个人风格化随笔。

## 输入

新闻事实或评论议题、权威文本与政策文件、项目指令中的口径要求。评论立意不确定时先提出 2-3 个立意方向供选择，不自行定调重大议题。

## 写作方法

1. **要闻消息**：导向正确、事实准确，政策表述以官方发布原文为准，不引申不演绎；会议与活动报道按审定议程组织，领导同志活动表述严格按权威通稿。
2. **评论结构**：立意从政策与全局出发；标题观点鲜明；正文按「提出问题—分析论证—结论主张」推进，论据须可核验。
3. **文风**：庄重规范，避免网络用语、夸张修辞与情绪化表达；成语典故引用准确，不确定出处的典故不用。
4. **引用纪律**：重要论述引用以权威文本为准并注明出处；文件表述引用到原文，概括不得改变原意。
5. **提法核对**：成稿后核对提法与现行规范表述的一致性；发现过时提法立即标记并给出现行表述。

## 工具与边界

政策原文核对使用系统实际提供的检索与文件读取能力；审校流程配合 workdsh-news-desk 技能执行。重大主题稿件按项目流程报备，本技能不替代报审环节。

## 交付与检查

交付稿件正文与提法核对记录。标准：政策表述可回溯到官方原文、评论论证链条完整、无未核对出处的论述引用。
