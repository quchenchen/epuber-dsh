# EpuberDSH 文档

[English](README.en.md)

从[用户指南](user-guide.md)了解安装与使用；[常见问题](faq.md)说明平台、运行时和更新边界。[为什么做 EpuberDSH](why-desktop.md)介绍产品定位。

开发者可阅读[架构说明](architecture.md)、[Desktop 归属约束](desktop-boundaries.md)、[插件开发](plugin-development.md)和[包级构建说明](../apps/desktop/README.zh.md)。官方运行时依赖固定版本的发布包及校验过的 Desktop 发布产物；EpuberDSH 的功能包由运行时 Profile 组合。

[插件生态倡议书](plugin-ecosystem.md)描述长期方向；当前没有独立的社区标准或在线市场运行包。

界面配色只有一处定义，接入新面板、改色与回滚的流程见[品牌配色与升级策略](brand-theme.md)。

根目录的 [`README.md`](../README.md) 是默认英文产品入口，[`README.zh-CN.md`](../README.zh-CN.md) 是中文入口。各 `.i18n.yaml` 记录相应双语文件的 Git blob hash，修改文档时应同步更新两种语言和记录。
