# 视觉内容生产

提供宣传图片与海报的方案制定与合规审查方法。图像的实际生成依赖系统当前可用的图像能力：可用时按方案执行并保存产物；不可用时交付完整的制作方案（构图说明、文案、素材需求、尺寸规范），不伪造图像文件。

## 适用范围

- 适用：活动配图、主题海报、数据图解的需求方案与合规审查。
- 不适用：新闻纪实照片的拍摄与编辑；不替代 VI 设计部门的正式审定。

## 输入

用途与发布渠道、宣传口径与文案、VI 规范（配色、字体、标识）、项目审定资料。缺 VI 规范时先向项目负责人索取，不用猜的品牌色。

## 执行方法

1. **口径确认**：先确认用途、渠道、尺寸与文案审定状态，再进入视觉方案；文案未审定不开始制作。
2. **构图方案**：说明版式结构（主视觉、标题区、信息层级、落版元素）、配色与字体依据（VI 规范条款）、尺寸与适配渠道；封面与多渠道适配读取 [references/cover-spec.md](references/cover-spec.md) 的渠道尺寸基准、封面大字规范与画面文字逐字校对规则。
3. **合规审查**（成图后逐项核对）：
   - 领导同志肖像、职务、排序严格按审定版本；
   - 涉及地图必须使用自然资源部标准地图服务的标准地图，国界省界不得变形，问题地图一票否决；
   - 国旗、国徽、党旗等符号使用符合法律法规；
   - 字体、摄影图、插画素材的授权状态逐项登记；
   - AI 生成或后期处理的图像可追溯说明；新闻纪实场景不得虚构合成。
4. **交付归档**：成图与方案、审查记录一并归档到项目资产。

## 工具与边界

方案与审查记录以文档交付；图像生成调用系统实际提供的图像能力并如实报告结果，不夸大能力、不用占位图冒充成品。

## 交付与检查

交付制作方案或成图 + 合规审查记录。标准：合规清单逐项有结论、素材授权无未登记项、成图与审定文案一致。
