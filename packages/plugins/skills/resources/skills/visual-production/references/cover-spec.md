# 封面规格与画面文字规范

海报与封面生产时的尺寸基准与文字可读性规范。平台规则随时可能调整，**以发布端现行要求为准**，以下为通行基准；企业自有渠道以 VI 规范为准。

## 渠道尺寸基准

| 发布端 | 常用规格 | 要点 |
|---|---|---|
| 微信公众号头图 | 900×383（约 2.35:1） | 次条封面 200×200 裁切安全；标题区避开右上角「标星」位置 |
| 微信视频号封面 | 1080×1260（竖版 6:7） | 上下预留 UI 遮挡区；首帧画面与封面同源时取同一构图 |
| 抖音/快手封面 | 1080×1920（竖版 9:16） | 字幕与标题避开底部进度条与右侧按钮区 |
| 微博配图 | 横版 1080×608（1.91:1）/ 九宫格 1080×1080 | 长图单独设计，不做等比拉伸 |
| 网站/客户端 banner | 按 VI 规范 | 同步提供 2x 分辨率源文件；响应式裁切给断点方案 |
| 内刊/印刷 | 出血版 + 印刷色彩模式 | CMYK 校色单独出稿，不用屏幕稿直印 |

一稿多用时先做**主体安全区设计**：主体与关键文案放在各端裁切共通区内，各端裁掉的是外围氛围区。

## 封面大字规范

封面标题字是封面信息的第一载体，可读性是硬标准：

- **字号下限**：发布端缩略图尺寸下仍可读——手机信息流里封面字小于正文正文字号即视为不合格；关键数字与主题词优先放大。
- **字数上限**：封面大字不超过 2 行，每行按端型控制（竖版约 8-12 字/行），超出就分层：主标题上封面，副题进摘要区。
- **对比度**：文字与背景对比不足时加蒙层或描边；弱光背景（夜景、深色设备）必须校验。
- **VI 一致性**：字体族、主色按 VI 规范条款，禁用字体写明替代；临时缺字体宁可重排不猜品牌字。

## 画面文字防错规则

画面内必须出现的文字（标识牌、数据屏、标语、人名牌）：

1. 需求描述中**写明确切字面内容**（逐字），不写「某某标识」这类模糊指代。
2. 设计/生成后**逐字校对**：错字、漏字、乱码、字形错误一律返工，不以「整体看没问题」放过。
3. 人名、职务、机构名与审定版本核对；数字与出处版本核对。
4. 校对记录进项目资产，封面定稿打版本号。
