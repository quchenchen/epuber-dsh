# 发布前合规审核

成品内容在对外发布前执行最后一道风控审核。与新闻审校台（workdsh-news-desk）分工：审校台审**稿件文字**，本技能审**成品发布包的全部公开面**——视频画面与声音、图文与封面、标题与话题标签、评论区引导、账号展示面。

## 核心规则

- 公开内容未经本道审核不得视为终稿。
- 证据缺失一律标「待核验」，不发明规则、事实、资质、授权与平台行为。
- 未审完所有可见、可听区域，结论不得为「通过」。
- 不提供法律意见，不替代平台或主管部门的最终决定；审核记录不冒充「已通过三审」状态。
- 默认以中文审核；项目指令与审定资料的专项要求叠加在通用风险区之上，冲突时以更严格者为准。

## 适用范围

- 适用：视频成片、图文推送、海报封面、多平台分发包的发布前风控审核。
- 不适用：稿件文字审校（走新闻审校台）、选题导向判断（走选题评估）、发布动作本身（发布须用户明确授权）。

## 输入

成品物料（视频文件或分镜终稿、图文与封面、标题文案）、目标平台与账号、项目审定资料与宣传口径、相关授权记录（肖像、素材、字体、音乐）。缺成品物料时降级为「脚本级预审」并在结论中注明；缺授权记录时把对应项列入待核验。

## 审核流程

1. **面遍历**。清点全部公开面并逐面处置：画面（含首帧、封面、贴纸）、声音（口播、同期声、BGM）、字幕、标题与摘要、话题标签、评论区置顶与引导、账号展示面（头像、简介、置顶内容）。每个面要么审到，要么列入未覆盖清单——「抽查过」不算审过。
2. **受监管领域识别**。涉及健康医疗、金融投资、未成年人、募捐、司法解释等领域，先核发布资质与授权范围，再进通用排查；无资质的领域内容按「阻断」处理。
3. **通用风险区排查**。读取 [references/risk-areas.md](references/risk-areas.md)，按九大风险区逐项过：每个问题落为「发现」时必须指认具体画面、声音或文字元素——只有敏感话题、没有具体风险元素的，不构成发现。
4. **项目特规叠加**。领导同志肖像与职务排序、标准地图、国旗国徽使用、口径表述等按项目审定资料与视觉内容生产技能的既定纪律执行，本审核复核其落实情况。
5. **结论与修复**。每个发现给出：位置指针（时间码、帧、段落或文本原文）、风险依据、具体修复建议（删改位置精确到可执行）；执行覆盖门后出分级结论。

## 严重度分级

- **阻断**：违法红线、重大导向问题、无资质受监管内容、明显侵权、明显虚假——修复前不得发布。
- **高**：很可能触发平台处置或严重投诉——修改或补证后发布。
- **中**：语境相关风险——修改、披露或保留更强证据。
- **低**：制作质量问题（字幕错字、比例错误、音画不同步、失效链接）。
- **通过**：已审范围内未发现实质风险（未覆盖区域必须另行列出）。

存在未解决的阻断级问题、或高等级问题未处置，发布包状态为「不可发布」。

## 修复建议模式

- **音频**：静音或替换精确区间，并同步修正对应字幕与卡片。
- **画面**：剪、换、裁、糊；风险帧不得进入封面、首帧与开头三秒。
- **表述**：去绝对化与保证性用语，补可验证出处，按审定口径改写。
- **权利**：替换未授权素材——只标注来源不能治愈未授权使用。
- **引流**：删除强制互动、虚假福利、站外联系方式与风险私信引导。
- **资质**：受监管内容补资质证明，或转为一般性、可支撑的信息陈述。

## 常见失败模式

- 改了字幕但风险语音还在。
- 只审正文，漏掉封面、开头三秒、BGM 与贴纸。
- 抽样帧看完就当全片审完，音频区段未审就下「通过」结论。
- 把识别工具（OCR/语音转写）的输出当作已验证事实。
- 隐瞒拿不准的出处、资质或素材授权，而不是标注「待核验」。
- 拿别的平台的公开内容当授权素材。

## 工具与边界

使用系统实际提供的文件读取、检索与多模态识别能力；能力不可用时如实说明并保持脚本级预审，不用「应该没问题」替代审核。审核不代用户发布、不代平台执法；审核记录与报告归档到项目资产。

## 交付与检查

交付审核报告：面遍历清单（已审面/未覆盖面）、发现清单（位置/依据/严重度/修复建议）、待核验清单、分级结论（可发布/修改后发布/不可发布）。复审以「发现清单清零 + 未覆盖区域补审或明确豁免理由」为标准，不以「看过了」为标准。
