# 分镜画面描述模板（八维法）

需要 AI 生成分镜参考图、关键画面视觉稿或视频首帧时使用。目的：把每一镜的画面意图写成**可复现、可校对**的描述，让静态视觉稿在低成本阶段确认构图、口径与文字信息。实际生成调用系统当前可用的图像能力；能力不可用时本模板作为拍摄参考图需求说明使用。

## 八维描述法

每镜画面描述按八个维度组织，写成连贯段落（不是机械罗列），缺失维度按场景取舍：

1. **主体（WHO）**：出镜人物或核心物体的身份、姿态、动作；人物须与制作资产登记中的设定一致（服装、岗位标识、工器具）。
2. **环境（WHERE）**：场景、空间结构、现场要素（设备、标识牌、安全设施）；场景要素与设定登记一致。
3. **动作（WHAT）**：正在发生什么——具体的作业动作、交互或事件，可拍摄、可执行。
4. **景别与构图（FRAME）**：远/全/中/近/特写，主体位置与画面重心；竖屏 9:16 或横屏 16:9 按目标端确定。
5. **镜头运动（CAMERA）**：固定、推、拉、摇、移、跟；生成参考图时写定格瞬间的动态感。
6. **光线（LIGHT）**：时间光线（晨光/正午/夜）、现场光源（路灯/屏幕光/工灯）、明暗氛围。
7. **画面文字（TEXT）**：画面内必须出现的文字（标识牌、屏幕内容、标语）**写明确切字面内容**，并声明「文字清晰正确无乱码」；纯装饰性测量数字删去。生成后必须人工校对字面，错误即重生。
8. **风格（STYLE）**：纪实、新闻纪实风格优先；动画或风格化表达单独声明，同一项目内风格统一，避免单镜漂移。

## 静态确认清单（首帧/参考图验收）

每张参考图过一遍再进下一环节：

- [ ] 构图与分镜表该镜描述一致（景别、主体、环境）
- [ ] 人物着装、岗位标识与设定登记一致
- [ ] 画面文字逐字正确，无乱码、无错字
- [ ] 涉及地图、企业标识、领导画面符合口径与合规要求
- [ ] 风格与同项目其他参考图统一

不通过的图：定位问题维度 → 修改描述 → 重生或改拍；问题出在设定登记的，先改登记再改单镜描述，防止同类问题在后续各镜重复出现。

## 使用纪律

- 参考图是**确认工具**不是成片素材：它的作用是低成本锁定构图与口径，新闻纪实内容不得以生成图冒充实拍。
- 一镜一描述，禁止把多镜打包进一次生成请求。
- 修改描述后重新生成前，先作废旧图，防止新旧图混用。
