# 新华社新闻稿写作

提供通讯社消息体例的写作方法。本技能为**公开通行体例的初版基线**：具体电头格式、发稿规范与审定口径以项目指令和项目审定资料为准。

## 适用范围

- 适用：消息、快讯、新华体综述等通稿。
- 不适用：评论文章、口播稿、软文。

## 输入

新闻事实与信源材料、体裁（快讯/消息/综述）、项目指令中的口径要求。缺少决定性事实时保留明确待补项，不臆测补齐。

## 写作方法

1. **电头与导语**：按项目审定格式使用消息头；导语回答最核心的一个问题，五要素中最重要的前置。
2. **倒金字塔**：第一段核心事实，其后段落按重要性递减；每段可独立删尾而不破坏前文完整性。
3. **一条一事**：快讯百字以内，消息 500 字左右；多主题拆成多条消息，不硬塞一篇。
4. **信源与引语纪律**：信源权威可核验；直接引语忠于原话并注明说话人身份；匿名信源须说明理由并经项目负责人确认后才可使用。
5. **硬事实核对**：人名、职务、机构名、政策文号、数字与计量单位逐一核对；成稿后自查五要素齐备，缺失要素在稿内显式标注。

## 工具与边界

信源核对使用系统实际提供的检索能力；审校流程配合 workdsh-news-desk 技能执行。本技能不负责发稿渠道操作。

## 交付与检查

交付符合体裁的通稿正文，附信源清单与五要素自查记录。标准：删掉任意后段不影响前段成立、引语逐字可核、无未标注的单一信源。
