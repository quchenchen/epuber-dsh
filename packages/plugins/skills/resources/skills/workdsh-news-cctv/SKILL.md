# 央视新闻稿写作

提供电视新闻播报文风的写作与改写方法。本技能为**公开通行体例的初版基线**：具体栏目风格、审定口径与禁用词表以项目指令和项目审定资料为准，冲突时以审定资料为准。

## 适用范围

- 适用：电视新闻消息稿、口播稿、新闻短片解说词。
- 不适用：平面深度报道、学术文章、新媒体娱乐化内容。

## 输入

新闻事实与信源材料、目标栏目与时长、项目指令中的口径要求。口径不明时先问清「主题主线要求与栏目」，不自行猜测宣传口径。

## 写作方法

1. **导语纪律**：导语一句话点明最核心事实，直接陈述，不设悬念铺垫；导语之后每段承载一个事实点，按重要程度递进。
2. **播报文风**：短句为主，一句一层意思；用常用词不用书面生僻词；数字口语化处理（「超过三成」优于「31.6%」时报口播）；避免长定语和嵌套从句。
3. **导向与称谓**：时政表述以权威通稿为准，专有名词、职务称谓使用规范全称；重要论述引用逐字核对。
4. **双版本交付**：口播稿（含停顿提示与易错音标注）与文字稿分开输出；解说词另附画面提示。
5. **安全播出自查**：成稿后逐条核对——导向表述、规范称谓、数字口径、引语原文、易错音与多音字；敏感议题标记「提请项目负责人确认」，不自行定稿。

## 工具与边界

信源核对使用系统实际提供的检索能力；审校流程配合 workdsh-news-desk 技能执行。本技能不负责播出编排与视频制作。

## 交付与检查

交付口播稿与文字稿双版本，附自查记录（逐条勾选）。标准：导语可直接上口、无超时长句、称谓与引语逐字可核、敏感点已标记待确认。
