# 三审三校组织方法

三审三校是出版与新闻单位的通行审校制度。本文件规定在项目协作中如何组织流程与记录，不替代单位内部的岗位职责规定；单位有正式制度时以正式制度为准。

## 角色与职责

| 环节 | 职责 | 输出 |
| --- | --- | --- |
| 初审（责任编辑） | 政治导向、事实准确性、体例规范、文字质量全面检查 | 初审意见 + 修改稿 |
| 复审（部门负责人） | 导向把关、重大事实复核、与既有口径一致性 | 复审意见 |
| 终审（总编/分管领导） | 发布决定、重大选题与敏感问题终裁 | 终审结论（发/改/撤） |
| 三校 | 校样与定稿逐字核对：错字、标点、数字、图文对应 | 校对记录 |

## 项目内组织方式

1. 每个环节在项目「计划」中建对应待办（如「初审：XX 稿」），负责人写实名，状态流转用待办状态（待处理/进行中/待确认/完成）。
2. 审校意见写进待办描述或活动记录：位置、原文、问题、建议，不只在对话里口头提。
3. 意见冲突不静默合并：记录双方意见，由终审角色裁定。
4. 敏感议题（重大主题、涉政策表述、争议事件）在初审即标记「提请终审」，不等到终审环节才发现。
5. 校对以「校对记录清零」为完成标准；复审、终审以明确结论为完成标准，不以「没有反对」为通过依据。

## 快速审校（时效稿）

时效紧张时允许压缩为「事实核验 + 导向自查 + 一校」，但必须在稿件元信息中记录「采用快速流程及原因」；重大主题稿件不得使用快速流程。
